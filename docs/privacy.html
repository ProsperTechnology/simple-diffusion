Simple Diffusion by Prosper Technologies generates images on your computer. It has no account requirement, image credits or telemetry.

Inside the app

Prompts, generated images, projects, references, masks, installed recipe packs and recovered drafts are stored on your PC. Inference uses local model files. The renderer cannot navigate to remote websites or call an external image-generation API. Copy diagnostics includes software and hardware status, excluding prompts, images and personal folder paths.

When the internet is used

  • Model setup downloads the pinned SDXL files from the model provider and verifies file hashes.
  • Opening official releases opens GitHub in your browser.
  • Optional test checkout opens Lemon Squeezy in your browser; the app does not collect payment card data. Live purchasing is disabled.
  • The updater is designed to contact GitHub when configured and enabled. Live checks and installation are disabled in this build.

External services can receive normal connection information such as your IP address and have their own policies. See GitHub privacy, Hugging Face privacy and Lemon Squeezy privacy.

This website

This static site is hosted on GitHub Pages. It uses locally hosted fonts and images, with no advertising, tracking scripts, analytics or contact forms added by Prosper Technologies. GitHub handles hosting and normal connection logs.

Application and model licenses

This public repository distributes product information and binaries. Simple Diffusion application source is privately maintained and no open-source license for the application is granted here. Third-party software retains its own licenses; Electron/Chromium and Python license notices ship with the installed components.

The image model is Stable Diffusion XL Base 1.0, governed by the CreativeML Open RAIL++-M license. Review it during setup. An app or style-pack purchase does not replace the model license or guarantee intellectual-property rights in generated outputs.

Style packs contain recipe data. They do not add a separate model, train on your images or guarantee exact faces, objects or output quality. Example artwork on this site was generated locally with the corresponding recipes. The app's decorative key visual is separate brand artwork and is not presented as engine benchmark evidence.

Reporting problems

Use the official issue tracker for non-sensitive reproducible bugs. Do not include private prompts, images, account credentials or personal system paths.
