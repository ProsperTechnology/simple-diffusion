GET STARTED / VERSION 0.5.0

A studio on
your own PC.

Simple Diffusion includes its own Python and NVIDIA image engine. You do not need to install Python, CUDA or developer tools separately.

Early-access testing build

This installer is unsigned. Windows may warn about an unrecognized publisher. A signed public build and broader hardware testing are still pending. If you prefer a signed application, wait for a signed release.

Check your requirements

ComponentRequirement
SystemWindows 10/11, 64-bit target; currently verified on Windows 11 only
GraphicsNVIDIA GPU, at least 8 GB VRAM; driver 560.94 or newer
MemoryAt least 16 GB system RAM
StorageAllow at least 20 GB free for setup and extraction; model is ~6.9 GB, installed app ~4.4 GiB, images require additional space
InternetRequired for installer/model downloads; generation works offline after setup
Test coverageRTX 4080, 16 GB VRAM. Physical 8/12 GB GPUs and fresh Windows machines remain unverified

AMD, Intel, CPU-only, macOS and Linux generation are not supported by this release. The lower-memory option does not substitute for validation on smaller GPUs.

Install in four steps

  1. Download the complete installer set.

    From the official v0.5.0 release, download Simple-Diffusion-Setup-0.5.0.exe, Simple-Diffusion-Setup-0.5.0-1.bin and Simple-Diffusion-Setup-0.5.0-2.bin. Keep all three files in the same folder. Do not rename them.

  2. Check the download.

    The release includes SHA256SUMS.txt. For an optional integrity check, run Get-FileHash .\Simple-Diffusion-Setup-0.5.0* -Algorithm SHA256 in PowerShell from your download folder and compare each value. A matching hash confirms file integrity; it is not a publisher signature.

  3. Open the setup executable.

    Use the setup wizard to choose the installation location. Do not open the .bin files directly. Downloading only the small .exe is insufficient.

  4. Set up the image engine.

    Open the app, review the hardware report and SDXL license, choose a model folder with free space and download the verified model. Setup supports interruption/resume and repair.

Make your first image

Choose Photography, Illustration or Stylized 3D. Describe one clear subject, choose a format, then press Create image. The first image loads the model and takes longer. Fast is useful for trying an idea; generation time depends on hardware and settings.

Where your work lives

The app keeps images, projects, references, installed packs and settings in its Windows user profile. You may choose a separate model folder. Changing that folder does not move or delete the previous model. Prompt/settings recovery is local; save a project to restore a reference image or painted selection.

If something goes wrong

  • Check Settings → Help & diagnostics. Copy diagnostics omits prompts, images and personal folder paths.
  • Use Set up / repair for missing or damaged model files.
  • Close other graphics-heavy programs or use the lower-memory setting if graphics memory is exhausted.
  • For a missing installer data file, put both .bin files beside the matching-version .exe.
  • Use the official issue tracker for reproducible bugs. Never post private prompts, images, account details or personal paths.
