0.5.1 October 30, 2026

Release hardening: compact desktop code, a bytecode-only first-party worker, archive/worker integrity checks, production debugging restrictions and fail-closed packaging guards.

These deter casual copying and tampering. Offline desktop code can still be reverse engineered. Previously downloaded versions cannot be recalled. Code signing remains pending; this is still an unsigned testing release with a single-download online installer that fetches and verifies engine data automatically.

0.5.0 October 30, 2026

A more personal, reliable studio.

Midnight and Paper appearances, Ctrl+K quick actions, canvas focus mode and local prompt recovery. Generation preparation now rejects overlapping jobs and honors cancellation before starting the engine.

  • New searchable quick actions with keyboard navigation.
  • Appearance is remembered on this PC.
  • Recover the last prompt, project name, format, quality and seed after restart. Saved projects restore reference/edit context.
  • Gallery search also matches style names.
  • Fixed mask-loading callbacks, stale reference state after choosing an example, duplicate Create submissions and a fast worker event race.
  • Updated Electron, React, build tools and test tools.
  • Rebuilt the public website, documentation and release information.

What was checked

20 automated test groups; actual local GPU generation, JPEG export, cancellation and painted-area editing; preparation concurrency checks; theme, keyboard, focus, recovery and compact-window checks; all five collections and 13 installed style recipes.

Current limits

Tested on Windows 11 with RTX 4080 / 16 GB. Physical 8/12 GB GPUs, fresh Windows machines and independent security review remain pending. The NVIDIA inference stack remains pinned for compatibility. One moderate advisory remains in a transitive build-only minimatch dependency; it is absent from the packaged production dependencies. This is not a claim of an independent security audit.
